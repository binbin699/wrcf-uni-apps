当设备开机且检测到未注册时，设备开启 BLE ⼴播以便 App 进⾏搜索和连接。BLE ⼴播

3. BLE ⼼跳包
为防⽌在配⽹过程中设备因节能策略⽽断开连接，App 每五秒向设备发送⼀次⼼跳包。
服务 UUID: 0000d0c1-0000-1000-8000-00805f9b34fb
特征 UUID (写): 0000d0df-0000-1000-8000-00805f9b34fb
数据: keep-alive
注意: 设备接收到⼼跳包后⽆需进⾏任何处理。4

5. BLE 配⽹
5.1 连接 WiFi
设备通过接收 SSID、密码尝试连接 WiFi。
服务 UUID: 0000d0c1-0000-1000-8000-00805f9b34fb
特征 UUID (写): 0000d0d2-0000-1000-8000-00805f9b34fb
数据格式: 使⽤换⾏符( \n , 0x0a )分割的⽂本数据，包括 SSID 和密码，字符编码
utf-8。
ID <ssid>
PWD <password>
示例:
WIFI SSID: wifi_ssid
密码: 12345678
编码后的数据:
0x49 0x44 0x20 0x77 0x69 0x66 0x69 0x5f 0x73 0x73 0x69 0x64 0x0a 0x50
0x57 0x44 0x20 0x31 0x32 0x33 0x34 0x35 0x36 0x37 0x386
5.2 设备注册
成功连接上 WiFi 之后，调⽤ HTTP 接⼝将设备注册到后端服务上，注册参数为第 2 步的
批次标识和设备唯⼀ ID（MAC 地址）。注册成功之后，后续业务交互直接使⽤注册时指定
的设备唯⼀ ID 即可。
注册接⼝： /childrenToy/bleDeviceActive/bindChildrenDevice
注册地址可能会通过服务配置协议更新。参考 4. 服务配置 写⼊数据的 r 字段。
参数 1 设备标识 activeKey ⻓度为 64 位的标识字符串（32 位 16 进制数值转换⽽
来）
示例： 118eb53478f7ce24c32141e186b26d8fe52066b90e74c940263026415657d1
bb
参数 2 设备唯⼀ ID bleDeviceId 这个 ID（MAC 地址）将⽤来注册设备以及后续业
务流程
示例： a1b2c3d4e5f6
根据返回值的 data 判断是否成功，该值为布尔值 true 成功 / false 失败
6. 状态反馈
设备根据连接 WiFi 的结果反馈相应的状态码。
服务 UUID: 0000d0c1-0000-1000-8000-00805f9b34fb
通知特征 UUID: 0000d0d3-0000-1000-8000-00805f9b34fb
数据格式: 0x6d 0x01 0x01 <status_code> 0x70
状态码定义:
0x00 : 开始配⽹
0x01 : 配⽹成功
0x02 : 配⽹失败：密码错误
0x03 : 配⽹失败：SSID 错误
0x04 : 配⽹失败：不⽀持的⽹络
0x05 : 配⽹失败：其他错误
0x0b : 设备注册成功
0x0c : 设备注册失败
0xa1 : 服务配置写⼊成功
0xa2 : 服务配置写⼊失败7
7. 配⽹流程结束
若设备注册成功，App 将断开 BLE 连接，设备随后可关闭 BLE ⼴播。
8. 错误处理
对于由于 WiFi 连接问题导致的配⽹失败，App 根据状态码提示⽤户重新输⼊正确的 SSID
和密码。
