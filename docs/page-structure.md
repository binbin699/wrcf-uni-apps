# 页面结构说明

## 📱 页面组织架构
```page
灵矽AI小程序
├── 登录页面 (Login)
├── 主页面 (TabBar)
│   ├── 我的AI助手 (Agent List)
│   └── 我的 (Profile)
├── 设备管理页面 (Device Management)
├── AI助手绑定弹窗 (Agent Binding Modal)
├── 添加设备弹窗 (Add Device Modal)
├── 蓝牙配网流程页面 (Bluetooth Config)
├── 创建私有AI助手页面 (Create Private Agent)
```

## 🎨 界面设计详解

### 1. 登录页面设计

**功能说明**：用户通过微信授权获取手机号进行登录

```page
┌─────────────────────────────────┐
│           小程序登录             │
├─────────────────────────────────┤
│                                 │
│         [应用Logo]              │
│                                 │
│         灵矽AI小程序            │
│                                 │
│    ┌─────────────────────┐      │
│    │   📱 手机号授权登录   │      │
│    └─────────────────────┘      │
│                                 │
│      通过微信授权获取手机号      │
│                                 │
└─────────────────────────────────┘
```

**技术实现**：
- 调用微信小程序授权API
- 获取用户手机号进行绑定登录
- 接口：`POST /app/user/login/miniPhone`

### 2. 主页面Tab1：我的AI助手

**功能说明**：展示用户可用的灵矽AI助手列表，支持公开/私有分类和创建功能

```page
┌─────────────────────────────────┐
│  ┌─────┐  ┌─────┐              │
│  │公开  │  │私有  │              │
│  └─────┘  └─────┘              │
├─────────────────────────────────┤
│                    [+ 创建]     │
├─────────────────────────────────┤
│                                 │
│  ┌─────┐  ┌─────┐  ┌─────┐     │
│  │🤖   │  │🤖   │  │🤖   │     │
│  │AI助手1│  │AI助手2│  │AI助手3│     │
│  │(公开) │  │(私有) │  │(公开) │     │
│  └─────┘  └─────┘  └─────┘     │
│                                 │
│  ┌─────┐  ┌─────┐              │
│  │🤖   │  │🤖   │              │
│  │AI助手4│  │AI助手5│              │
│  │(私有) │  │(公开) │              │
│  └─────┘  └─────┘              │
│                                 │
├─────────────────────────────────┤

│  我的AI助手  │      我的        │
└─────────────────────────────────┘
```

**功能特性**：
- 底部Tab切换：公开AI助手 / 私有AI助手
- 右上角"+ 创建"按钮，用于创建私有AI助手
- 网格布局展示AI助手卡片，标注公开/私有状态
- 点击AI助手触发设备绑定流程
- 接口：`GET /app/agent/list?type=public|private`
- 创建接口：`POST /app/agent/create`

**功能说明**：设备列表展示和删除操作

```page
┌─────────────────────────────────┐
│  ← 设备管理                     │
├─────────────────────────────────┤
│                                 │
│  ┌─────────────────────────┐   │

│  └─────────────────────────┘   │
│                                 │
│  ┌─────────────────────────┐   │
│  │ 📱 设备名称2             │   │
│  │ MAC: XX:XX:XX:XX:XX:XX  │   │
│  │ 绑定智能体: 未绑定       │🗑️ │
│  └─────────────────────────┘   │

│  ┌─────────────────────────┐   │
```

**功能特性**：

- 接口：`GET /app/device/list`、`DELETE /app/device/remove`
- 配网接口：`POST /app/device/bluetooth-config`

### 5. 智能体绑定弹窗

**功能说明**：选择设备与智能体进行绑定
```page
┌─────────────────────────────────┐
│          选择设备绑定            │
├─────────────────────────────────┤
│                                 │
│  智能体：智能体A                │
│                                 │
│  ┌─────────────────────────┐   │
│  │ ○ 设备1 (客厅音箱)       │   │
│  │   MAC: AA:BB:CC:DD:EE:FF │   │
│  └─────────────────────────┘   │
│                                 │
│  ┌─────────────────────────┐   │
│  │ ● 设备2 (卧室音箱)       │   │
│  │   MAC: 11:22:33:44:55:66 │   │
│  └─────────────────────────┘   │
│                                 │
│    ┌─────┐    ┌─────┐          │
│    │ 取消 │    │ 确定 │          │
│    └─────┘    └─────┘          │
│                                 │
└─────────────────────────────────┘
```

**交互流程**：
1. 显示当前选择的智能体
2. 列出用户的所有设备
3. 单选设备进行绑定
4. 确认后调用绑定接口
5. 接口：`POST /app/agent/bind`

### 7. 创建私有AI助手页面

**功能说明**：用户创建个人专属的私有AI助手

```page
┌─────────────────────────────────┐
│  ← 创建私有AI助手               │
├─────────────────────────────────┤
│                                 │
│  助手名称：                     │
│  ┌─────────────────────────┐   │
│  │ 请输入助手名称           │   │
│  └─────────────────────────┘   │
│                                 │
│                                 │
│  助手描述：                     │
│  ┌─────────────────────────┐   │
│  │ 请描述助手的功能和特点   │   │
│  │                         │   │
│  │                         │   │
│  └─────────────────────────┘   │
│                                 │
│                                 │
│    ┌─────┐    ┌─────┐          │
│    │ 取消 │    │ 创建 │          │
│    └─────┘    └─────┘          │
│                                 │
└─────────────────────────────────┘
```

**功能特性**：
- 自定义助手名称和头像
- 添加助手功能描述
- 接口：`POST /app/agent/create`

**创建流程**：
1. 填写基本信息（名称、头像、描述）
2. 选择知识库配置
3. 预览助手设置
4. 确认创建
5. 返回助手列表
