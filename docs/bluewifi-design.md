# "我的"页面 → 设备配网流程设计

基于蓝牙配网规范和小程序项目结构，设计完整的设备配网用户流程。

## 📱 流程概览

### 基础信息
- **小程序AppID**: 935b6aac310c088b0d30a261cccdce27
- **配网入口**: "我的"页面 → 设备配网
- **支持平台**: 微信小程序、支付宝小程序、百度小程序等
- **技术方案**: BluFi协议 + uni-app框架
- **目标设备**: XIAOLING* 或 BLUFI_DEVICE* 命名的蓝牙设备

## 🛠️ 技术实现要点

### uni-app页面结构
```page
src/pages/
├── mine/
│   └── index.vue          # "我的"页面
├── device-config/
│   ├── index.vue          # 配网引导页
│   ├── bluetooth.vue      # 蓝牙搜索连接
│   ├── wifi-list.vue      # WiFi列表选择
│   ├── wifi-password.vue  # WiFi密码输入
│   ├── configuring.vue    # 配网进行中
│   └── result.vue         # 配网结果
```
